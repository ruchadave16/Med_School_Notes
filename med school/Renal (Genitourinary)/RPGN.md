### Etiology


### Pathophysiology
- Rapid loss of renal function 
- 20% = anti-GBM antibody mediated
	- Antibodies against Type IV [[Collagen]]in basement membrane -> linear pattern
	- IF pulmonary involvement, then called [[Goodpasture Syndrome]]
	- If not, then [[Goodpasture Syndrome|anti-GBM disease]]
- 25% = immune complex formation ([[lupus nephritis]])
	- Treat underlying disease
- 55% = [[Pauci Immune Glomerulonephritis|Pauci immune GN]] (no deposits)
	- ANCA + 

- Formation of glomerular crescents

### Clinical Features
- Oliguria
- [[Nephritic Syndrome]]

- Labs
- Imaging
- Criteria

### Treatment
- Benefit from plasmapheresis if angi-GBM
- Progressive -> [[dialysis]] or transplant

### Complications
- Fatal if untreated
