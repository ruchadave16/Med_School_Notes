*Feedforward: Receives and sends input to cerebrum, making changes based on current body position*
*Feedback: Takes in proprioceptive info to compare to actual movement and correct timing and velocity*

- Helps with planning movements and correcting them
- Flow: input -> cerebellar cortex -> [[deep cerebellar nuclei]] -> thalamus / brainstem

#### Anatomy
- 2 hemispheres with midline vermis
	- Medial portion of lateral hemispheres = paravermis
- Folia = small folds in between gyrus

Cross-section
- White mater = arbor vitae
- Outer cortex
- [[Deep cerebellar nuclei]] = gray matter

![[Screenshot 2026-04-09 at 12.03.21 PM.png]]

Hemisphere
- Anterior lobe
- posterior lobe
- Flocculonodular lobe

Tonsils (most caudal part of posterior lobe)

>[!Note] Tonsillar Herniation
>- Respiratory failure (medullary respiratory centers)
>- Altered consciousness (reticular activating system)
>- Potential long-tract signs (CST, DCML, STT)
>- Develop hydrocephalus or syringomyelia
>- Tonsil herniation present in Chiari Malformation

#### Regions
- Lateral hemispheres (cerebrocerebellum)
	- Movement planning
	- Input = [[Primary Motor Cortex|motor cortex]] -> [[Internal Capsule]] -> cerebral peduncles -> synapse in pontine nuclei -> cross in pons and enter middle cerebellar peduncle
	- Dentate nuclei
	- Output = C/L VL [[thalamus]] -> [[Primary Motor Cortex|motor cortex]]
- Paravermis (spinocerebellum)
	- Limb movement coordination
	- Input = [[Spinocerebellar Tracts]] and [[Pontocerebellar Tract]]
	- Interposed nuclei
	- Output = C/L red nuclei -> [[rubrospinal tracts]] OR C/L VL thalamus -> [[Primary Motor Cortex|motor cortex]]
- Vermis (spinocerebellum)
	- Coordinates trunk and eye / head movement
	- Input = [[spinocerebellar tracts]]
	- Fastigal nuclei
	- Output = [[vestibular nuclei]] -> VeST, ICP -> bilat. [[reticular formation]] -> ReST, SCP -> C/L VL thalamus -> [[Primary Motor Cortex|motor cortex]] -> [[Corticospinal Tract|corticospinal tract]]
- Flocculonodular (vestibulocerebellum)
	- Posture and gaze stability
	- Vestibular nuclei = input and processing
	- Output: I/L vestibular nucl. -> MLF -> ocular motor nuclei, ICP -> I/L vestibular nucl. -> I/L VeST
#### Cerebellum Input
- 4 [[Spinocerebellar Tracts]] that carry unconscious proprioceptive and internal motor feedback to cerebellum
	- Enter through inferior cerebellar peduncle
	- *Lesion = [[cerebellar ataxia]]*
- [[Pontocerebellar Tract]] from [[Primary Motor Cortex|motor cortex]]
	- Sends info abt planning and intended action
	- Cerebral cortex sends info -> [[pontine nuclei]]
	- Fibers cross in pons and enter through middle cerebellar peduncle
- Vestibular Information
	- [[Vestibule|Vestibular apparatus]] -> vestibular nucl. -> cerebellum
- [[Inferior olivary nucleus]]
	- Motor learning pathways
	- Olivocerebellar fibers -> C/L cerebellum
#### Cerebellum Output
- VL thalamus -> motor cortex
- Red nucleus -> rubrospinal tract
	- C/L -> flexors for muscle tone
- 4 vestibular nuclei -> vestibulospinal tracts and ocular motor nuclei
- [[Reticular formation]] -> reticulospinal tracts
