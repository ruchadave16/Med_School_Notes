- Homeostasis, olfaction, memory, and emotions
#### Structures
- [[Hypothalamus]] -- homeostasis
	- Infundibulum -> post. pituitary
- [[Olfactory bulb]] and tract -- olfaction
	- Olfactory stria -> piriform complex, periamygdaloid cortex, and amygdala
- [[Hippocampus]] -- memory
	- Fornix -> mammillary bodies
- [[Amygdala]] -- emotions
	- Stria terminalis -> hypothalamus + septal nuclei
	- Amygdalofugal pathway
- [[Septal Nuclei]]
	- Fornix -> hippocampus
- Nucleus basalis
	- Below anterior commissure
	- Damage in [[Alzheimers Disease|Alzheimers]]
- Cingulate gyrus
	- Cingulum -> parahippocampal gyrus
- [[Mammillary bodies]]
	- Mammillothalamic tract -> thalamus
- Brainstem nuclei
- [[Thalamus]]
