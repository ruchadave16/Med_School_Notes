UMN:
- C/L [[primary motor cortex]] -> [[Internal Capsule|internal capsule]] (genu) -> cerebral peduncles -> [[brainstem]] -> synapse on CN nuclei

Nerves: V, upper VII, IX-XI bilat, lower VII, XII C/L

LMN:
- [[ventral horn]] -> ventral root -> spinal nerve -> muscle

*Lesion* -- pseudobulbar palsy (looks like LMN but is UMN lesion)

>[!Info]
>Most motor CN nuclei get bilateral input from corticobulbar so no symptoms from lesion
>- Exception: [[Facial nucleus]] (lower face, C/L) from  unilateral lesion
>- Exception: Hypoglossal nucleus ([[genioglossus]], C/L deviation)
>
